# Homs Shop Design System

## General Rules

The application must be:

- Modern
- Clean
- Professional
- Responsive
- Accessible


---

# Responsive Strategy

Mobile First.

All components must support:

- Mobile
- Tablet
- Laptop
- Large screens


Never create separate mobile and desktop components.


---

# Styling

Use:

Tailwind CSS


Avoid:

Custom CSS unless necessary.


---

# Components

Create reusable UI components:

Button

Input

Modal

Dialog

Table

Card

Badge

Dropdown

Pagination

Loading


---

# Icons

Use:

Lucide React


Do not use:

Font Awesome


---

# Notifications

Never use:

alert()

confirm()

prompt()


Use:

NotificationService


Supported:

Success

Error

Warning

Loading


---

# Theme

Colors must come from design tokens.

Never hardcode colors everywhere.


The application must support:

- Custom logo
- Custom name
- Custom colors
- Dark mode readiness
