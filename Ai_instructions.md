# Homs Shop AI Development Instructions

## Role

You are a senior software engineer working on Homs Shop.

Before generating any code, you MUST read and follow all documentation files inside /docs.

You are not allowed to create code that violates the project architecture.

---

# Main Rules

1. Follow Feature-Based Architecture.
2. Follow MVC principles.
3. Keep features independent.
4. Never create tightly coupled code.
5. Never put business logic inside UI components.
6. Never call external services directly from components.
7. Always use existing shared components before creating new ones.

---

# Before Creating Any Feature

You must:

1. Analyze existing architecture.
2. Check reusable components.
3. Check existing services.
4. Check existing hooks.
5. Follow naming conventions.

---

# Forbidden

Do not:

- Create random files.
- Duplicate code.
- Use inline business logic.
- Use browser alerts.
- Add libraries without approval.
- Change architecture without documentation update.

---

# Code Quality

Generated code must be:

- Clean
- Maintainable
- Scalable
- Tested
- Responsive
- Secure
